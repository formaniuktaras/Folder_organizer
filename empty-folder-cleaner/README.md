# Empty Folder Cleaner

**Empty Folder Cleaner** — це Windows-додаток на Python (PySide6), який знаходить папки за вказаними назвами та видаляє **тільки повністю порожні**.

## Можливості
- Вибір головної директорії для сканування.
- Список назв папок (по одній назві в рядок).
- Асинхронне сканування в окремому потоці (QThread/Worker).
- Кнопка **«Зупинити сканування»** для акуратного завершення пошуку.
- Тестовий режим (dry-run): без фактичного видалення.
- Безпечне видалення лише перевірених кандидатів із останнього сканування.
- Керовані налаштування захищених директорій.
- Експорт результатів у CSV.
- Детальний журнал подій.

## Налаштування захищених директорій
У головному вікні є кнопка **«Налаштування»**.

У вікні налаштувань доступно:
- список захищених директорій;
- **«Додати директорію»**;
- **«Видалити зі списку»**;
- **«Очистити список»**;
- чекбокс **«Увімкнути захист директорій»**;
- чекбокс **«Блокувати також вкладені папки захищених директорій»**.

Логіка:
- якщо захист вимкнений — список захищених директорій не блокує сканування/видалення;
- якщо захист увімкнений — сканування блокується для шляху, який входить у захищені директорії (з урахуванням вкладеності, якщо ввімкнений відповідний прапорець);
- під час видалення додатково перевіряється належність до захищених директорій.

> Програма **не має hardcoded системних заборон**. Шляхи на кшталт `G:\...` блокуються тільки якщо користувач сам додав їх у список захисту.

## Важливі обмеження безпеки
- Програма ніколи не видаляє **головну директорію**, яку вибрав користувач.
- Видаляються тільки папки зі статусом **«порожня»** з останнього сканування.

## Налаштування (`settings.json`)
Зберігаються:
- остання головна директорія;
- список назв папок для пошуку;
- стан тестового режиму;
- стан **«Увімкнути захист директорій»**;
- стан **«Блокувати також вкладені папки»**;
- список захищених директорій.

Початкові значення:
- захист директорій: **вимкнено**;
- блокування вкладених папок: **увімкнено**;
- список захищених директорій: порожній.

## Вимоги
- Python 3.10+
- Windows 10/11

## Запуск з Python
```bat
python -m pip install -r requirements.txt
python main.py
```

## Збірка `.exe`
```bat
build_exe.bat
```

Скрипт встановлює залежності і викликає PyInstaller з назвою:
- **`Empty Folder Cleaner.exe`**

Після збірки виконуваний файл буде в папці `dist`.

## Як користуватись
1. Натисніть **«Обрати папку»** і виберіть головну директорію.
2. Введіть список назв папок для пошуку.
3. За потреби налаштуйте **«Захищені директорії»**.
4. Натисніть **«Сканувати»**.
5. За потреби натисніть **«Зупинити сканування»**.
6. Перевірте таблицю результатів.
7. Натисніть **«Видалити порожні»**:
   - у тестовому режимі буде лише позначка `буде видалено`;
   - у звичайному режимі після підтвердження папки будуть видалені (`видалено`).
8. За потреби виконайте **«Експорт результатів у CSV»**.
