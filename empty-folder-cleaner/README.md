# Empty Folder Cleaner

**Empty Folder Cleaner** — це Windows-додаток на Python (PySide6) з двома режимами:
1. **Очищення порожніх папок**.
2. **Перевірка каталогу**.

## Можливості
- Окремі вкладки для режимів очищення та перевірки каталогу.
- Асинхронне сканування в окремому потоці (QThread/Worker).
- Зупинка сканування користувачем.
- Експорт результатів у CSV (UTF-8 with BOM, сумісно з Excel).
- Детальний журнал подій.

## Режим 1: Очищення порожніх папок
- Вибір головної директорії.
- Пошук папок за списком назв.
- Тестовий режим (dry-run).
- Видалення тільки підтверджених порожніх / умовно порожніх папок.
- Налаштування захищених директорій та ігнорованих файлів.

## Режим 2: Перевірка каталогу

### Що робить
Рекурсивно шукає цільові каталоги в джерелі, а для кожного знайденого каталогу перевіряє наявність еталонних підпапок. Після перевірки можна безпечно створити відсутні еталонні папки.

### Поля
- **Джерело сканування** + кнопка **«Обрати папку»**.
- **Каталоги, які потрібно знайти** (по 1 назві в рядку).
- **Папки, які мають бути всередині кожного каталогу** (по 1 назві в рядку).

### Налаштування
- **Ігнорувати регістр літер** (типово: увімкнено).
- **Ігнорувати зайві пробіли на початку і в кінці назв** (типово: увімкнено).
- **Показувати повні шляхи** (типово: увімкнено).
- **Перевіряти тільки безпосередні підпапки всередині знайденого каталогу** (типово: увімкнено).

### Статуси
- **повний** — всі обов'язкові папки є, зайвих немає.
- **повний із зайвими** — всі обов'язкові папки є, але є додаткові.
- **неповний** — частина обов'язкових папок відсутня.
- **не знайдено** — каталог зі списку не знайдений.
- **дублікат** — знайдено декілька каталогів з однаковою назвою.
- **помилка** — неможливо прочитати каталог (PermissionError/FileNotFoundError/OSError).

### Створення відсутніх папок
- Кнопка **«Створити відсутні для вибраного»** працює тільки для вибраного рядка, якщо в ньому є відсутні папки.
- Кнопка **«Створити всі відсутні»** створює відсутні папки для всіх знайдених каталогів, де це дозволено.
- Кнопки неактивні під час сканування і активуються після завершення перевірки, якщо є що створювати.
- Перед створенням показується вікно підтвердження з переліком/підсумками.
- Для масового створення показується окреме попередження, якщо в результатах є **дублікати**.

#### Правила безпеки створення
- Створюються **лише** папки з еталонного списку «Папки, які мають бути всередині кожного каталогу».
- Каталоги зі статусом **«не знайдено»** та **«помилка»** не змінюються.
- Для **«дублікат»** дозволено створення для конкретного рядка; у режимі «всі» потрібне додаткове підтвердження.
- Перед кожним `mkdir` повторно перевіряються доступність каталогу, валідність назви та наявність у результатах останнього сканування.
- Папки створюються через `pathlib.Path.mkdir(exist_ok=True)`.
- Функція **не видаляє** і **не перейменовує** нічого.

#### Оновлення таблиці та журнал
- Після створення рядки таблиці оновлюються: перераховуються «Знайдено обов'язкових папок», «Відсутні папки», статус і коментар.
- У «Коментар» записується:
  - `Відсутні папки створено`
  - `Частково створено, є помилки`
  - `Пропущено: каталог недоступний`
- Журнал містить старт операції, режим (вибраний/всі), план/факт створення, кількість пропусків/помилок і деталі помилок із шляхами.

### CSV-експорт перевірки каталогу
Колонки:
- дата і час перевірки;
- джерело;
- назва каталогу;
- статус;
- шлях;
- знайдено обов'язкових;
- всього обов'язкових;
- відсутні папки;
- зайві папки;
- коментар.

## Налаштування (`settings.json`)
Зберігаються як попередні налаштування очищення, так і окремий блок:

```json
"catalog_check": {
  "source_path": "",
  "target_catalogs": "",
  "required_folders": "",
  "ignore_case": true,
  "trim_spaces": true,
  "show_full_paths": true,
  "direct_children_only": true
}
```

## Приклад використання режиму «Перевірка каталогу»
- Каталоги для пошуку:
  - `Діт до 4.1.3`
  - `Діт до 4.1.4`
- Обов'язкові папки:
  - `01_Матеріали`
  - `02_Фото`
  - `03_Скани`
  - `04_Документи`

Після сканування таблиця покаже, де структура повна, де є зайві папки, де бракує папок, а що взагалі не знайдено.

## Вимоги
- Python 3.10+
- Windows 10/11
