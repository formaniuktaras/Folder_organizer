# Empty Folder Cleaner

**Empty Folder Cleaner** — це Windows-додаток на Python (PySide6), який знаходить папки за вказаними назвами та видаляє **тільки повністю порожні**.

## Можливості
- Вибір головної директорії для сканування.
- Список назв папок (по одній назві в рядок).
- Асинхронне сканування в окремому потоці (QThread/Worker).
- Кнопка **«Зупинити сканування»** для акуратного завершення пошуку.
- Тестовий режим (dry-run): без фактичного видалення.
- Безпечне видалення лише перевірених кандидатів із останнього сканування.
- Експорт результатів у CSV.
- Детальний журнал подій.

## Важливі обмеження безпеки
Програма **блокує** сканування/видалення для системних директорій, зокрема:
- корінь будь-якого диска (`C:\`, `D:\`, ...);
- `C:\Windows`;
- `C:\Program Files`;
- `C:\Program Files (x86)`;
- `C:\ProgramData`;
- `C:\Users`;
- `C:\Users\<поточний_користувач>`;
- `C:\Users\<поточний_користувач>\Desktop`;
- `C:\Users\<поточний_користувач>\Documents`;
- `C:\Users\<поточний_користувач>\Downloads`.

> ⚠️ Програма видаляє **лише повністю порожні папки** (без файлів і підпапок).

## Вимоги
- Python 3.10+
- Windows 10/11

## Запуск з Python
```bat
python -m pip install -r requirements.txt
python main.py
```

## Збірка `.exe`
```bat
build_exe.bat
```

Скрипт встановлює залежності і викликає PyInstaller з назвою:
- **`Empty Folder Cleaner.exe`**

Після збірки виконуваний файл буде в папці `dist`.

## Як користуватись
1. Натисніть **«Обрати папку»** і виберіть головну директорію.
2. Введіть список назв папок для пошуку.
3. Натисніть **«Сканувати»**.
4. За потреби натисніть **«Зупинити сканування»**.
5. Перевірте таблицю результатів:
   - `порожня` / `кандидат на видалення`;
   - `не порожня` / `пропущено`;
   - `помилка` / `пропущено`.
6. Натисніть **«Видалити порожні»**:
   - у тестовому режимі буде лише позначка `буде видалено`;
   - у звичайному режимі після підтвердження папки будуть видалені (`видалено`).
7. За потреби виконайте **«Експорт результатів у CSV»**.

## Тестовий режим
За замовчуванням увімкнено чекбокс **«Тестовий режим без видалення»**. У цьому режимі:
- жодна папка фізично не видаляється;
- у таблиці дія для кандидатів змінюється на **«буде видалено»**;
- можна безпечно перевірити, що саме буде оброблено перед реальним видаленням.
